Issue #367 — 迁移 REPL 到 internal/cli/repl — 2026-07-28

Design Decisions

Decision Export exactly one entry point: repl.Run(repl.Options{})

Ambiguity: The issue names runInteractive->Run and interactiveOptions->Options but does not say what else must cross the package boundary.

Choice: Exported only Run and the Options struct with all 16 fields (Model, ProviderName, Provider, BaseURL, APIKey, Protocol, ThinkingLevel, Tools, SysPrompt, ResumeID, Approve, Skills, Plugins, ConfigPrompts, CliPrompts, NoPromptTemplates). Everything else — replDeps, runREPL, replLineEditor, buildSlashRegistry, loadPromptPaths, promptTemplateSources — stays package-private.

Rationale: run.go is the sole cross-package caller; a single exported constructor keeps the seam minimal and lets the REPL internals evolve freely. Mirrors the established pattern from #364/#365/#366.

Deviations

Deviation prompts_config_test.go split across two packages

Spec: "对应 *_test.go 迁入并转为 package repl" reads as moving whole test files.

Implemented: Split the file — TestApplyFileConfigPrompts (drives cliOptions/applyFileConfig, both in package main) stays in cmd/pigo; the three tests exercising loadPromptPaths/buildSlashRegistry/promptTemplateSources moved to internal/cli/repl since those symbols moved with the REPL.

Why: A test must live in the package that owns the unexported symbols it calls. cliOptions/applyFileConfig are CLI-parse concerns that stay in main (per #369's thin-entry goal), so a clean split is the only compiling option.

Tradeoffs

Tradeoff git mv + perl package-rename over hand-editing 19 files

Alternatives: (a) manually move and re-clause each file; (b) git mv in bulk then perl-rewrite the package clause.

Pros/cons: (b) preserves rename history in the diff and is fast, but files with leading comment blocks before package main needed a second targeted perl pass (first-match ^package main) since \Apackage did not match.

Winner: (b) — history-preserving and verifiable via "no package main remaining" grep; build/vet/test gate correctness.
