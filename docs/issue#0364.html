Implementation Notes

Issue #364 — 迁移 /goal 到 internal/cli/goal (US-008) — 2026-07-28

Design Decisions

Decision /goal decoupled from package main via the cli.Host contract

Ambiguity: The spec asked to move /goal into internal/cli/goal, but /goal reaches deep into the session's mutable state (agent context, live config, goal state, session store) that lived on the concrete replDeps struct in package main.

Choice: RunGoal takes host cli.Host and reads every collaborator through Host accessors (host.AgentCtx(), host.Live(), host.Goal(), …) instead of importing replDeps.

Rationale: goal must not import package main (cmd/pigo); the Host seam keeps the dependency single-direction (repl→goal) and avoids an import cycle, matching the pattern already used by /compact and /fork.

Decision Shared REPL helpers relocated to neutral packages before the goal move

Ambiguity: /goal reused three renderers (renderToolResult/toolCallLabel/oneLine) and persistTurn that were private to package main.

Choice: Moved the renderers to internal/cli/ui (RenderToolResult/ToolCallLabel/OneLine) and persistTurn to internal/cli (PersistTurn(out, Host)), then rewired repl.go, btw.go and goal.go to the shared versions.

Rationale: Both repl(main) and goal now depend downward on neutral packages with no duplication and no cycle, rather than goal reaching sideways into main.

Deviations

Deviation PersistTurn no longer mutates the in-memory header timestamp

Spec/original: The old persistTurn set deps.header.UpdatedAt in place, so the live struct carried the fresh timestamp after a persist.

Implemented: Host.Header() returns a value copy, so PersistTurn stamps UpdatedAt on that copy and passes it to AppendBranch; the disk record is correct but the in-memory deps.header.UpdatedAt is not advanced by PersistTurn.

Why acceptable: No in-process reader depends on the freshness of deps.header.UpdatedAt after a persist — the /compact path stamps it independently before its own Save, and header timestamps are read from disk-loaded headers when listing sessions. Persistence is behavior-equivalent.

Tradeoffs

Tradeoff Host accessor pattern vs. exporting replDeps

Alternatives: (a) export replDeps and its fields so goal could import it; (b) pass a narrow cli.Host interface.

Pros/cons: (a) is fewer lines but forces goal to import package main (impossible — cycle) or forces replDeps into internal/cli (a large, main-specific aggregate). (b) adds one accessor call per field but keeps packages loosely coupled.

Chosen: (b) — the Host contract already existed from #357 and is the established seam for control commands; reusing it keeps the migration consistent with #362/#363.
