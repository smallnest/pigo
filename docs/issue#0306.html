Design Decisions

Decision 扩展现有「技能 Skills」章节，而非新建文档

Ambiguity: issue 只说「更新 README / skills 相关文档」，未指定放在哪、是否新建页面。

Choice: 在 README 现有的「技能 Skills」章节内追加一个「模型自动调用（渐进式披露）」小节，并在 frontmatter 字段列表中补上 disable-model-invocation。

Decision 显式说明「仅当 read 工具可用时自动调用才生效」

Ambiguity: read 工具依赖是实现细节，文档层面是否要暴露给用户并不明确。

Choice: 在小节中明确写出 --no-tools 或屏蔽 read 时不注入 <available_skills>，并解释原因（模型需 read 才能加载正文）。

Rationale: 这是 AC 的硬性要求，也解释了为何某些配置下技能「不会被自动调用」，减少用户困惑。
