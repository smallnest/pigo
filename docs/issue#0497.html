Issue #497 — 站点骨架与共享样式 — 2026-08-01

Design Decisions

Decision 双语用 data-en/data-zh 内联属性，而非中央字典

Ambiguity: PRD 只要求"中英切换 + localStorage 持久化"，未规定实现方式。

Choice: 每个元素直接写 data-en/data-zh，i18n.js 遍历赋值 innerHTML；无集中 key 字典。

Rationale: 多页静态站无构建，内联属性让每页文案自包含、易维护，新增页无需改动共享脚本。

Decision 顺带实现暗/亮主题切换

Ambiguity: PRD 要求暗色主题、亮色可选。

Choice: CSS 变量 + html[data-theme]，默认 dark，data-theme-toggle 按钮切换并持久化。

Rationale: 与 i18n 同一持久化机制，成本低且满足"配色全站统一"。

Deviations

Deviation 复制按钮/导航样式也一并纳入骨架

Spec: #497 仅列 site.css + i18n.js + 目录。

Implemented: site.css 额外包含 nav / hero / feature-row / docs 布局 / footer / 代码块复制样式。

Why: 这些是所有后续页面共享的样式，集中在骨架里避免 #498–#506 各自重复定义。

Tradeoffs

Tradeoff innerHTML 赋值 vs textContent

Alternatives: textContent（更安全）或 innerHTML（支持内联标记）。

Chosen: innerHTML —— 文案来自作者写死的 data 属性（非用户输入），可含 <b>/<code> 等标记，无 XSS 面。
